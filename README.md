# 🌐 Bernardino Lintang – Portfolio Website

[![Vercel Status](https://img.shields.io/badge/Deployed%20on-Vercel-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://bernardino-lintang-website.vercel.app/)

This is my personal **portfolio website**, built to showcase my background, projects, and achievements as a **Data Science & Analytics student** at the National University of Singapore (NUS).  
The website is deployed live at: 👉 [bernardino-lintang-website.vercel.app](https://bernardino-lintang-website.vercel.app/)

---

## ✨ Features
- **About Me** – quick introduction, education, and interests.  
- **Projects** – highlights of my key data science, machine learning, and web development work.  
- **Tech Stack** – clean showcase of the tools and technologies I use.  
- **Contact Section** – links to LinkedIn, email, and GitHub for easy networking.  

---

## 🛠️ Tech Stack
- **Frontend:** [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [TailwindCSS](https://tailwindcss.com/)  
- **Build Tool:** [Vite](https://vitejs.dev/)  
- **Deployment:** [Vercel](https://vercel.com/)  

---

## 🚀 Local Development
If you want to run this project locally:

```bash
# Clone the repo
git clone https://github.com/bernardinolintang/BernardinoLintangWebsite.git

# Navigate into the folder
cd BernardinoLintangWebsite

# Install dependencies
npm install

# Start the dev server
npm run dev
